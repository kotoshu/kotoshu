Overview

The Stage-2 result: every resource Kotoshu::ResourceManager.resolve found for one language, ready to hand to Spellchecker.new.

A member is nil for any resource that was not requested in the want: list or is not set up. The bundle is cache-only data — building one never touches the network.

Examples:

Kotoshu.setup(:en)
bundle = Kotoshu::ResourceManager.resolve(language: "en")
bundle.dictionary  # => #<Kotoshu::Dictionary::Hunspell ...>
bundle.has_model?  # => false (model not requested)
