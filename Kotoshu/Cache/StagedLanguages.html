Overview

Offline-safe snapshot of the languages staged in the kotoshu/dictionaries manifest (plan 107).

manifest.json in the dictionaries repo is the single source of truth for what kotoshu setup can download; this module vendors its language codes so the hot path never needs the network to answer "is this language downloadable?" (resolve is cache-only by contract, and the spelling gate runs inside #available?).

The list is regenerated by

rake kotoshu:staged_languages:sync

which fetches the manifest at the SourceRegistry pin, extracts the distinct language codes from its resources, and rewrites CODES in place. Edit the dictionaries repo, not this file.

Two tiers of support (plan 107 vocabulary):

  • full feature: a language module under Kotoshu::Languages (keyboard layout + verified specimens + tokenizer care) — see LanguageCache.full_feature_languages;
  • basic: manifest-present but module-less — the script fallback tokenizer and generic keyboard still serve check/suggest.
