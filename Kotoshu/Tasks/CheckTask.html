Overview

Rake task checking a repository text files with the plan-88 file selection (plan 89, item 3).

Examples:

Default task via require

# Rakefile
require "kotoshu/tasks"
# provides rake kotoshu:check over the repo text files

Configured

Kotoshu::Tasks::CheckTask.new do |t|
  t.files = FileList["_posts/**/*.md"]
  t.language = "en"
  t.fail_on_error = true
end
