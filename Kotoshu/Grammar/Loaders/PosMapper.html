Overview

Maps LanguageTool POS tags (Penn Treebank style, with LT-specific extensions) onto the reduced Kotoshu tagset (TODO.grammar/7).

LT stores tags either as exact atoms ("VBZ") or — with postag_regexp="yes" — as alternations/patterns ("NN.*", "DT|PRP\$", "VB", "NNP?S"). This mapper decomposes both forms into symbols understood by PosSequenceMatcher#pos_match?, including the hierarchical groups (:VERB covers all verb subtypes, :NOUN covers singular/plural/proper).

def map(postag, regexp: false)
  return nil if postag.nil? || postag.empty?
  return EXACT[postag] if EXACT.key?(postag)

  regexp ? map_regexp(postag) : nil
end
