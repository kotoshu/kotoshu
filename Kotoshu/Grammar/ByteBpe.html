Overview

Byte-level BPE tokenizer for GPT-2-style vocabularies (distilroberta and friends) — the Ruby twin needed to run the grammar tagger fully locally through onnxruntime.

Ids are exactly what HuggingFace produces; the spec replays a fixture generated by the reference tokenizer (byte-identical).

GPT-2 byte-to-unicode table: printable ranges map to themselves; the remaining 68 bytes map upward from U+0100.

begin
  table = {}
  printable = ((33..126).to_a + (161..172).to_a + (174..255).to_a)
  n = 0
  (0..255).each do |b|
    table[b] = [printable.include?(b) ? b : 256 + n].pack("U")
    n += 1 unless printable.include?(b)
  end
  table.freeze
end

def initialize(vocab_path, merges_path)
  require "json"
  @vocab = JSON.parse(File.read(vocab_path))
  @merges = {}
  File.foreach(merges_path).with_index do |line, i|
    next if i.zero? # version header

    pair = line.split(" ")
    @merges[[pair[0], pair[1]]] = i - 1 if pair.length == 2
  end
  @cache = {}
end

def alignment(words)
  align = [nil]
  words.each_with_index do |w, i|
    align.concat(word_ids(w.to_s).map { i })
  end
  align << nil
  align
end

def encode(text)
  ids = [BOS]
  text.scan(PRETOKENIZE) { |piece| ids.concat(word_ids(piece)) }
  ids << EOS
end

def encode_words(words)
  ids = [BOS]
  words.each { |w| ids.concat(word_ids(w.to_s)) }
  ids << EOS
  ids
end
