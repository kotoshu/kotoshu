Overview

Urdu POS tagger over the CLE tagset (issue #279) — the lexicon variant of PosTagger. The purchased 100k-word human-reviewed CLE corpus compiles into the lexicon (word → tag); until then the tagger covers the small closed classes that are stable Urdu grammar (postpositions, auxiliaries, negation, punctuation) and answers UNKNOWN for open-class words, so callers can route unknown tokens however they need.

The serving contract matches PosTagger: tag returns [pos:, index:] per token.

def compile_lexicon(pairs)
  pairs.each do |word, tag|
    next unless Grammar::PosTagset::Ur.tag?(tag)

    @lexicon[word] ||= tag
  end
  @lexicon.size
end

def tag(text)
  tokenize(text).each_with_index.map do |word, i|
    { word: word, pos: pos_for(word), index: i }
  end
end

def tag_reduced(text)
  tag(text).map do |tok|
    tok[:reduced] = REDUCED[tok[:pos]] || :UNKNOWN
    tok
  end
end
