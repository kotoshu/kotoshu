Overview

Greek language implementation (plan 84, wave 1).

Greek-aware composition: the Greek tokenizer keeps Greek-script words (the Latin tokenizer's letter checks would drop them), and the Greek normalizer handles the two script-specific folds:

  • final sigma: ΕΛΛΑΣ folds to ελλας (ς), not ελλασ (σ), matching dictionary forms;
  • optional accent stripping (πάτησις -> πατησις) for accent-insensitive comparison, off by default because Greek Hunspell dictionaries carry accents.

Keyboard proximity uses the Greek phonetic grid (Keyboard::Layouts::GreekPhonetic).
